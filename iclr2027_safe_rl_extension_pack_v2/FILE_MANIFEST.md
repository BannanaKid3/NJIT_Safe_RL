# Package manifest

- `README_FIRST.md`: overview and important caveats.
- `RUN_ORDER.md`: exact sequence and commands.
- `INSTALLATION_MAP.md`: every destination generated inside the repo.
- `SOURCE_SNAPSHOT.md`: source commit/blob snapshot used for patch matching.
- `VALIDATION_REPORT.md`: checks completed before packaging.
- `experiment_matrix.csv`: paper experiment matrix.
- `setup_pipeline.py`: installer/generator for full trainer files.
- `experiment_extensions/`: shared Quadrotor and Swimmer cost/environment helpers.
- `env_profiles/quadrotor/`: explicit active perturbation YAML pairs.
- `tools/`: profile switching and preflight checks.
- `calibration/`: Swimmer joint-speed calibration.
- `analysis/`: two-seed checkpoint and ablation analysis.
- `paper_plotting/`: common paper-plot helper.
- `scripts/`: numbered PowerShell launchers.
- `examples/`: manual command equivalents.
- `tests/`: lightweight logic checks.
